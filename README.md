A one-line code review comment that approves a pull request with quiet existential dread: the code will outlive the company, the on-call rotation, and eventually the reviewer — merging anyway. Entry for the make.fun bounty "Two Days of Quiet Dread".

## Run it

```sh
python3 main.py
```

It writes the comment to `/output/entry.txt` (103 characters, one line, deterministic).
